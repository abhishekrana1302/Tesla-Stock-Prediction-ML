# Tesla Stock Price Prediction using Machine Learning

This project uses historical Tesla stock market data to predict
whether the next day's closing price will increase or decrease.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Dataset
Historical Tesla stock price data containing:
Date, Open, High, Low, Close, Volume, and Adj Close.

## Machine Learning Models
- Logistic Regression
- Support Vector Machine
- XGBoost

- Stock_Price_Prediction.ipynb
